# بوابة الصيادين — دليل التشغيل

## مهم قبل النشر
- توكن تيليجرام الذي أُرسل في المحادثة يجب اعتباره مكشوفًا: افتح **@BotFather** وألغِه/جدّده، ثم استخدم التوكن الجديد فقط. لا تضع التوكن داخل الكود أو تشاركه.
- هذا المشروع يحتاج استضافة تدعم Python/Flask (وليس مجرد رفع ملف HTML). أمثلة: Render أو Railway أو خادم Python خاص.
- بيانات المستخدمين محفوظة في `event_data.json`. استخدم تخزينًا دائمًا أو قاعدة بيانات في الاستضافة حتى لا تضيع البيانات عند إعادة التشغيل. للتشغيل التجريبي المحلي يعمل الملف تلقائيًا.

## تشغيل محلي
1. ثبّت Python 3.11 أو أحدث.
2. داخل مجلد المشروع نفّذ:
   `pip install -r requirements.txt`
3. عيّن متغيرات البيئة `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` و`FLASK_SECRET_KEY`.
4. شغّل: `python app.py`
5. افتح `http://127.0.0.1:5000`.

## نشر عبر خدمة تدعم Python
- ارفع محتويات المجلد إلى مستودع Git أو إلى منصة الاستضافة.
- أمر البناء: `pip install -r requirements.txt`
- أمر التشغيل: `gunicorn app:app`
- أضف المتغيرات من ملف `.env.example` في إعدادات الاستضافة. لا ترفع ملف `.env` الحقيقي إلى Git.
- فعّل التخزين الدائم للملف `event_data.json` أو عدّل المشروع لاستخدام قاعدة بيانات مُدارة.

## محتويات الموقع
- تسجيل اسم كونايو، وإشعار تسجيل عبر تيليجرام.
- اختبار أنمي من 20 سؤالًا، 15 ثانية لكل سؤال، محاولة واحدة مسجلة لكل اسم حساب.
- اختيار فصيل النور أو الظلام، أو الخالدين (+10 نقاط) بعد تحذير وتأكيد.
- قضية جنائية خيالية مع مستندات وخانة إرسال استنتاج للإدارة.
- استراحة محارب، مع موافقة منفصلة قبل إرسال الرد للنشر.
- معلومات المطوّر وتصنيفات النقاط.

## ملاحظات فنية
- هذه نسخة أولية لفعالية صغيرة. تسجيل الدخول يعتمد على اسم كونايو المدخل وليس تحققًا من ملكية الحساب، ولذلك يمكن لشخص إدخال اسم شخص آخر. إذا كانت الفعالية تنافسية، أضف رمز تحقق/تسجيلًا إداريًا قبل احتساب النتائج.
- منع تكرار الاختبار يتم على اسم كونايو المسجل، وليس بصمة الجهاز؛ يمكن للشخص تغيير الاسم أو استخدام متصفح آخر. لا يُجمع اسم الجهاز أو بيانات بصمة المتصفح.
- الترتيب يعرض رقم ترتيب المستخدم وعدد من أكملوا الاختبار فقط؛ لا يعرض أسماء المشاركين الآخرين.
- الاختبار لا يكشف الإجابات الصحيحة أثناء اللعب. مهلة السؤال تُدار من الواجهة مع تحقق أساسي في الخادم؛ لتحكيم تنافسي أقوى يلزم إنشاء جلسة اختبار موقعة في الخادم.
- القضية خيالية، والحل المقترح يؤكد أن الأدلة لا تكفي لاتهام شخص دون قرينة حاسمة إضافية.
